# 設計簡報 v2：熱聲研究導覽頁——動畫單元群

> 用途：貼給 Claude Design。以既有 frame **3a 的圖示感為基準語彙**，逐單元產出視覺原型（JSX）。
> 產出交回 Claude Code 移植 Astro；移植時 Code 會逐項驗算動畫物理（相位連續性、聲流方向、脫渦時序、C 圖曲線），設計階段以視覺與構圖為主，物理照本簡報的方程走即可。
> 上一輪 frame 收斂裁定：**3a 為主軸**發展；文字樹本體採 1b 三欄表格式；2a 的文獻時間軸概念併入 1b；1a 淘汰。

## 一、視覺語彙三分

- **A 裝置全景**：3a 同款——深色底（#05080f）、管件漸層、部位中英標籤、橙色聲功流箭頭、淡藍氣體微團、單一往復流時鐘驅動全場。
- **B 放大視窗**：全景上的圓形/圓角矩形 zoom inset，同一時鐘、比例尺放大，演微觀物理。
- **C 數據圖動畫**：黑底同款座標軸語彙（細灰軸線、等寬字刻度），曲線用管件同色系，⟨本實驗室⟩相關元素才用紅 #dc2626。C 圖一律配一個 3a 風「迷你裝置圖示」當硬體錨點。

共同規則：動畫過渡 150ms ease-out 心跳除外（各單元主循環週期 4–8s）；無陰影無漸層濫用；深色只用於動畫畫布，畫布之外的頁面內容（樹、清單）回白底。

## 二、單元目錄（優先序：第一波 A1 微調＋C2＋C3＋B1）

### A. 裝置全景

**A1 行波迴路 TAS 引擎**（既有 3a，微調兩處）
- 圖說「四種非線性效應」改為「**基礎效應＋三種非線性效應**」：①微團接力搬熱屬線性基礎效應，與②聲流③次損失④紊流性質不同。
- 保留 Penelet 2014／Swift 2017 ch.7 出處註記。

**A2 駐波引擎＋喇叭驅動製冷機**（新，雙件小全景）
- 左：直管駐波引擎（stack＋兩端熱交換器，開口/閉口端標駐波腹節）；右：喇叭驅動的駐波製冷機（Hofler 構型）。
- 附**量測視窗**：共振管上兩個壓力感測點 p₁、p₂ 發亮，旁邊小讀數框即時顯示聲功 W=½Re[p₁U₁*]——two-sensor 法示意（⟨lab⟩ 開放工具，紅點標記）。

**A3 液柱系統**（新）
- Fluidyne／液柱史特靈：U 型液柱在兩氣柱間往復（頻率 f=(1/2π)√(2g/L) 的重力模態）、氣柱側有蓄熱器。
- ⟨lab⟩ 紅標掛「液柱」主題（已發表線）；視覺可與教學區 Fluidyne 動畫共享 DNA 但這裡是研究視角（標議題不標製作）。

### B. 放大視窗

**B1 跨界氣塊**（掛 A1 蓄熱器–共振管接口）
- 一顆氣塊半行程在蓄熱器細流道內（位移小、貼壁、等溫色），半行程衝出到粗管（截面積比 ~10:1，速度驟降、位移大、絕熱色），界面下游側每半週期交替脫渦。
- 議題標籤:有限振幅、入口效應與接合條件。

**B2 熱交換器振盪流熱傳**（掛 A1/A2 熱交換器）
- 氣塊在平行板間往復,吸熱段紅、放熱段藍,與位移相位差可視;角落註「振盪流熱傳至今無完整理論」（open problem）。

**B3 邊界層三區制**
- 氣塊與壁距離 y/δ_α 三檔：≫1 絕熱可逆（不變色）、≈1 不可逆（色相位滯後,做功閃光）、≪1 等溫可逆（即時變色）——站上介紹頁圖 3 的動畫化,構圖沿用該圖語彙。

**B4 濕蓄熱器**（B1 變體;⟨lab⟩ 紅標,只掛已發表的 JSV 濕蓄熱器線）
- 流道壁掛液膜,氣塊往復時膜面蒸發/凝結微光,強調相變增強效應;不出現任何實驗參數。

### C. 數據圖動畫（方程照此實作）

**C1 波形陡峭化＋頻譜級聯**
- 左圖波形：Fubini 解 p(θ;σ)=Σₙ [2Jₙ(nσ)/(nσ)]·sin(nθ)，n=1..12；σ 由 0.05 動畫推進到 1.0（激波形成）。
- 右圖頻譜柱：Bₙ(σ)=2Jₙ(nσ)/(nσ)，隨 σ 同步長高——能量由基頻逐級下灌。
- 迷你圖示：加熱直管引擎。

**C2 分岔圖（超臨界 vs 亞臨界，可切換）**
- 縱軸振幅 r、橫軸控制參數 μ（≡ΔT−ΔT_c 標示為溫差）。
- 超臨界：dr/dt=μr−r³ → 分支 r=√μ（μ>0），實線穩定、r=0 在 μ>0 轉虛線。
- 亞臨界：dr/dt=μr+r³−r⁵ → 上分支 r²=(1+√(1+4μ))/2，下（不穩定）分支 r²=(1−√(1+4μ))/2，摺點 μ*=−1/4。
- 互動：游標沿 μ 掃描,亞臨界模式來回掃出**遲滯跳躍**（μ↑在 0 起跳、μ↓在 −1/4 落回）;旁附小視窗顯示對應時域波形（雜訊→增長→飽和）。
- 迷你圖示：同一支直管引擎＋加熱器色溫隨 μ 變。
- ⟨lab⟩ 紅點暫不掛（成果投稿中,見刊後加）。

**C3 同步與振幅死寂（雙聯畫）**
- 左：兩支直管引擎,中間閥＋細管耦合（琵琶實驗構型,3a 風迷你全景）,各配一條即時波形。
- 右：耦合強度 K–失諧 Δω 平面相圖,三區：I 漂移（各振各的）、II 鎖定（Arnold 舌）、III 振幅死寂（高 K 島,Biwa 教科書 Fig 9.8 樣式）。
- 模型：耦合 Stuart–Landau，ż₁=(1+iΔω/2)z₁−|z₁|²z₁+K(z₂−z₁)、ż₂=(1−iΔω/2)z₂−|z₂|²z₂+K(z₁−z₂)。區界設計階段可手繪近似（舌形自原點張開、死寂島在 K≳1 高失諧側）,移植時 Code 以數值掃描供精確邊界。
- 互動：游標在相圖上移動,左邊兩台引擎波形即時漂移→鎖定→雙雙熄滅。

**C4 龐加萊截面（三檔切換）**
- 模型：週期驅動 van der Pol,x″−μ(1−x²)x′+x=F cos(ω_d t)，μ=1、ω_d/ω₀ 取黃金比 0.618;頻閃取樣周期 2π/ω_d。
- 三檔 F：鎖定（截面＝單點/少數點）→ 準週期（點沿閉曲線鋪開）→ 混沌（散點雲）;左側附對應時域波形。
- 迷你圖示：直管引擎＋ΔT 三檔旋鈕。
- 點雲資料移植時由 Code 供精確數據,設計階段自行積分或示意皆可。

## 五、交付格式

- 每單元一個獨立 JSX 函式元件（或單檔多 export）,不用外部 UI 庫;SVG＋CSS keyframes 為主,需要逐幀計算的（C 圖）用 requestAnimationFrame。
- 各單元的可調參數與資料寫成檔頭 const（C 圖的曲線資料留成可替換陣列,Code 移植時灌入精算值）。
- 單一往復流時鐘：每個畫布用一個主相位變數驅動所有元素,方便移植時統一對時。
