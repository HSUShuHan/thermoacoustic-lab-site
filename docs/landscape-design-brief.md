# 設計簡報：熱聲研究導覽頁（/research/landscape）

> 用途：貼給 Claude Design 做視覺原型。產出單一 JSX（React）檔交回 Claude Code 移植成 Astro。
> 品牌完整規範見 design skill（thermoacoustic-lab-design）；本簡報已濃縮必要約束。

## 一、頁面目標與受眾

國立臺北科技大學熱聲實驗室官網（thermoacoustictw.org）的「領域導覽」專頁。
受眾：想入門熱聲的潛在研究生（主要）、同行研究者（次要）。
頁面回答兩個問題：**這個領域有哪些主題、從哪篇讀起？**（知識樹）／**現在世界上誰在做？**（團隊清單，已有現成版面）。

## 二、頁面結構

1. 頁首：標題「熱聲研究導覽」＋一段引言（2–3 句）
2. **主題知識樹**（本次設計重點）
3. 團隊與公司清單（既有元件：國別列框線表格，沿用不必重設計；設計時放個佔位示意即可）

## 三、知識樹設計需求

### 資料結構（三層）
- **分支**（7 支）：入門讀物／歷史與自激發聲／基礎理論／關鍵元件／裝置／量測方法／設計・模擬・AI／應用與產業化
- **葉節點**：主題名＋掛兩種內容：
  - 奠基文獻 1–3 筆（作者、期刊縮寫、年份；可連 DOI）
  - 現役團隊 chip（連到下方清單錨點）
- **⟨本實驗室⟩節點**：約 9 個葉子掛本實驗室的研究／工具，需視覺強調（紅色系，是全頁唯一的強調色用途）——訪客一眼看出實驗室在領域全景中的位置，這是本頁對招生的核心價值。

### 互動
- 分支可摺疊／展開（預設：全部收合、或首支展開，設計師判斷）
- 展開動畫極簡（150ms ease-out，只動 opacity／高度）
- 文獻條目 hover：底色極淡變化即可
- 手機：單欄、縮排變窄、可摺疊行為不變

### 內容樣本（設計用，非最終定稿）

```
▸ 基礎理論
  ▾ 流道與多孔介質聲學模型
      奠基：Kirchhoff (1868) · Stinson, JASA (1991) · Ueda et al., JASA (2009)
      現役：[Dragonetti] [本實驗室 ●濕蓄熱器/金屬網]
  ▸ 非線性熱聲
  ▸ 振盪動力學與不穩定性
▸ 裝置
  ▾ 行波／迴路管系
      奠基：Ceperley, JASA (1979) · Yazaki et al., PRL (1998) · Backhaus & Swift, Nature (1999)
      現役：[長谷川] [于志斌] [本實驗室 ●]
```

完整樹（7 支、約 25 葉）見 knowledge-tree-draft.md；設計時做 2 支展開＋其餘收合的狀態即可。

## 四、品牌約束（必守）

- **色**：白底；主色 navy `#1e3a5f`（brand-800，深階 `#172b47`）；灰階 `#374151`／`#6b7280`／`#e5e7eb`；紅 `#dc2626` **僅**用於⟨本實驗室⟩強調與 hover，不做大面積
- **字**：標題 Noto Serif TC 600；內文 Inter + Noto Sans TC 400/500；行高 1.6；英文標題 sentence case
- **形**：卡片 4px 圓角、1px `#e5e7eb` 邊框、**無陰影**；控制元件 2px 圓角；無 pill 形
- **禁**：漸層、半透明、emoji、裝飾性 unicode（▸▾ 這種功能性箭頭可以）、誇飾文案、正文 em-dash
- 參考現有頁面質感：thermoacoustictw.org/research/thermoacoustic-effect/（頁尾清單的國別框線表格就是既有語彙）

## 五、交付格式

- 單一 JSX 檔（函式元件＋useState 摺疊即可），不用外部 UI 庫；樣式用 Tailwind utility class（站上是 Tailwind 4）或 inline style
- 資料寫成檔頭的 const 陣列（tree = [...]），方便移植時替換為真實資料
- 中文為主；葉名可留英文欄位但設計以中文版為準
